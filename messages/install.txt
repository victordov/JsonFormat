JsonFormat installed.

Open the Command Palette and type "JsonFormat:" to format, minify, convert
or validate JSON, JSONC and JSON5. Selections are formatted on their own;
with no selection the whole file is formatted.

Folding: use the "JsonFormat: Collapse ..." and "Expand All" commands.
No key bindings are installed; see "Preferences: JsonFormat Key Bindings"
for suggestions. Format on save is off by default. See
Preferences > Package Settings > JsonFormat.

JsonFormat runs entirely inside Sublime Text: no external Python, no
third-party libraries, no network access.
